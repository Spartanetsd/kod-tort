# Код «Торт»: привітання для Сергія Сластенка

Інтерактивне привітання з днем народження в стилі виклику: картка іменинника, MARCH для торта, турнікет на швидкість, свічки, бліц-іспит і фінал з медаллю «За врятований настрій».

## Файли (усі в одній папці, без підпапок)

- `index.html` — застосунок, фото вбудоване всередину
- `sirena.wav`, `uspikh.wav`, `pomylka.wav`, `klats.wav`, `fiksatsiia.wav`, `podykh.wav`, `vohon.wav`, `fanfara.wav` — звуки
- `ikonka.png` — іконка вкладки й домашнього екрана
- `README.md` — ця інструкція

## Як опублікувати з iPhone

1. На GitHub створи новий репозиторій, наприклад `kod-tort`, тип Public.
2. Розпакуй архів у «Файлах» (торкнись його), потім у репозиторії: Add file → Upload files → вибери всі файли → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт відкриється за адресою `https://<твій-логін>.github.io/kod-tort/`.

## Звук

- Звук вмикається після першого натискання: так вимагають браузери.
- Кнопка «Звук / Тиша» вгорі праворуч вмикає і вимикає звук.
- Застосунок просить у Safari режим відтворення, тому на нових iOS звук має грати навіть у беззвучному режимі. Якщо тихо, перевір перемикач беззвучного режиму й гучність.
- Якщо `.wav` не завантажились (наприклад, `index.html` відкрито напряму, без GitHub Pages), застосунок сам синтезує ті самі звуки.
